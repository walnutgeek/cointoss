# v0.0.2

Dependency upgrade: woodglue 0.0.9 replaces its token list with Users, Roles and tokens.

## Changed

- **CLI** (`cointoss.cli`): `cointoss init` and `cointoss token` use woodglue's `AuthStore`
  and its built-in `admin` User instead of the removed `woodglue.token_store`. Output is
  unchanged. An existing `auth.db` is migrated on first open, and its token keeps working
  as the admin token. When the admin User holds several tokens, `cointoss token` refers to
  `wgl token` to list them.

## Documentation

- Design docs removed from `main` after v0.0.1; they remain under the `v0.0.1` tag.

## Dependencies

- woodglue 0.0.9 (from 0.0.8), lythonic 0.0.28 (from 0.0.27).
