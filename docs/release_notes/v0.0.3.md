# v0.0.3

Explorable data: a generic Dataset read API, a Streamlit explorer served by woodglue, and
backup / restore for an instance.

## New

- **Backup and restore** (`cointoss.backup`): `cointoss backup DEST` copies the database
  (SQLite backup API, safe while the server runs) and the YAML configs into a new directory
  with a `manifest.json`, holding `sweep.lock` so no sweep writes mid-copy.
  `cointoss restore SRC` puts a backup into a stopped instance with no `cointoss.db`.
  `auth.db` is not part of a backup.
- **Dataset read API** (`cointoss.datasets`, ADR-0010): two new JSON-RPC nodes,
  `datasets()` lists every Dataset with its typed, role-tagged columns and params schema;
  `frame(dataset, params)` returns a long lythonic `FrameData`. First Datasets:
  `instruments`, `bars`, `returns` (derived on read, close to close, never spliced across
  sources), `membership`, `changes`, `runs`. Responses are capped at 250k rows.
  `cointoss.datasets.load(client, name, **params)` returns a typed pandas DataFrame.
- **Dataset explorer** (`cointoss.explorer`, `cointoss.explorer_app`): a Streamlit app that
  discovers Datasets and lets a viewer filter, chart and pivot them, served by woodglue at
  `/ui/explore/` under the viewer's own delegated token. Install the new `ui` extra
  (`cointoss[ui]`: pandas, Streamlit). `cointoss init` adds `uis.explore` to a new
  `woodglue.yaml`; for an existing one it prints the snippet to add.

## Changed

- **Scheduled sweep** (`cointoss.app`): when another process holds `sweep.lock` (a backup),
  the scheduled sweep waits up to 10 minutes instead of giving up.

## Documentation

- Docs site: working API reference pages for every module, a Design section (glossary,
  road map, ADRs), a privacy page, strict builds in CI. README links the site and the
  privacy page and shows CI and docs badges.

## Dependencies

- New optional extra `ui`: pandas >= 2.2, streamlit >= 1.40.
